MAIL CLEANER

Désabonnez-vous des newsletters et nettoyez votre boîte Gmail

1. Configuration

Cette application fonctionne 100 % dans votre navigateur : vos emails ne transitent par aucun serveur tiers. Il vous faut un identifiant OAuth Google (gratuit, 5 minutes) :

  1. Ouvrez la Google Cloud Console et créez un projet.
  2. Activez l'API Gmail (Bibliothèque d'API → Gmail API → Activer).
  3. Configurez l'écran de consentement OAuth (type « Externe », ajoutez votre adresse comme utilisateur test).
  4. Créez un identifiant « ID client OAuth » → « Application Web » et ajoutez l'origine de cette page () dans « Origines JavaScript autorisées ».
  5. Collez l'ID client ci-dessous (il se termine par .apps.googleusercontent.com).

2. Connexion

Connectez-vous à votre compte Gmail pour commencer.
